# QuickEats 🍔

A responsive food delivery website demo, built with HTML and CSS.

**🔗 Live demo:** https://nickelfrank110-hub.github.io/quickeats/

## Features
- Mobile-friendly layout (1 column on phones, 2 on larger screens)
- Dark theme with orange accents
- Menu cards with images, prices in Ksh, and hover effects
- About section and contact form
- Smooth navigation between sections

## Built with
- HTML5
- CSS3 (Flexbox, Grid, media queries)

## Run it locally
1. Download or clone this repo.
2. Open `index.html` in your browser.
